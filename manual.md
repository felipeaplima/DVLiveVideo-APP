# 📘 DV Live Video – User Manual

## What is this app?

This application was created to help DataVolley 4 users perform real‑time video analysis during a match. In the official DV4 app, you only have access to the last 5 rallies. With this tool, your scout file (`.dvw`) and video capture file (`.mp4`) allow you to search any rally, apply powerful filters, and share the analysis with everyone on your network.

## How it works

The app continuously monitors the scout file (updated during the match) and associates it with the video capture or a third capture URL. When using the capture (`.mp4`) the app generates a new live HLS stream (HTTP Live Streaming) that can be watched in any web browser, supporting seeking backwards (DVR), so you can replay any rally from the beginning of the match.

> **📌 Tip:** For access the `.dvw` file, it is recommended to use the **automatic backup on an external drive** available in DV4 (*Scouting Options → Scouting Safety*). If your laptop has an SD card slot, use it as a backup disk for better performance.

## Minimum Requirements

- **VLC Player** installed on the laptop – the desktop app uses VLC plugins.
- **ffmpeg.exe** placed in the same folder as the application `.exe`.
- If you want to capture the streaming on another computer that is not the same as scouting, you will need either an application to create a secondary stream starting at the same time as the DV4 capture, or the **Science Untangled scoutfile-sender app** (provided in the .rar) that will share your scoutfile on your network.
- Some options to use another streaming source on your network include: 
  [**VolleyStation Streamer**](https://storage.volleystation.com/downloads/software/VolleyStation-Streamer-win-latest.exe), OvenMediaEngine (OME), MediaMTX, and others.

## First steps

When receiving the `.rar`, unzip all files in the same folder at your disk:

- **Make sure VLC is installed in your laptop;**
- **You can test the application with some past match data (`.dvw` and `.mp4`)**
- **You'll need free space for temporary video files, it's recommended to have up to 10GB because your main `.mp4` file will be duplicated twice to make it accessible in the web client and desktop app!!**

## Starting the app and choosing a video source

> **📌 Attention:** In the first open of this application, it can take more than 1 minute to load it!!!

Run the `DVLiveVideo.exe` on the unziped folder. You can later set this `.exe` as a shortcut in your taskbar and start menu.

You can start the app in three modes:

- **Desktop + Web Server** – full desktop interface + web player.
- **Desktop only** – only the local PyQt5 window (no web server).
- **Web server only** – only the web interface (no desktop window).

After choosing the type of running, you need to choose one of two video sources:

### 1. Scout's DV capture file (`.mp4`)

In the second dialog, select the partial `.mp4` file generated by DV4 and the corresponding `.dvw` scout file. Every time the scout file is updated, the app copies the partial video and assign to the scoutfile allowing rally searchs. For the web server each 2 rally updates the app regenerates the HLS stream for everyone in the network. This update frequence can be modified according to the quality of processor and network.

### 2. An existing stream on the same network (`.m3u8` playlist)

For now, the native DV4 stream URL cannot be used because it doesn't allow backward search. However, you can use any other HLS stream (for example VS Stream). Important: even in this mode, the `.dvw` scout file must be associated with a video capture to generate timestamps. If the secondary stream is not perfectly synchronized, use the **offset field** (in seconds) to align it with the main capture.

## Using the Application

### Desktop Interface

- **Play/Pause** – button or `Space`.
- **Seek +5s / -5s** – buttons or `←` `→` (arrows).
- **Seek +2s / -2s** – `-` and `+` keys.
- **Offset** – adjust the time compensation (positive or negative seconds) applied when clicking a rally.
- **Filters** – filter rallies by set, home/away rotation, and search with wildcard `_` (e.g., `a__S_#` finds serves with '#' evaluation).
- **Favorites** – click the star (or press `F`) to mark a rally. Use the "Show only favorites" checkbox.
- **Fullscreen** – button or `ESC` to exit.
- **Dark/Light mode** – 🌙/☀️ button.

### Web Interface (Browser)

Access the web player at `http://[server-ip]:5000`. Features include:

- Same video player with **seek buttons** (2s, 5s) and offset control.
- Filters, favorites, and wildcard search identical to the desktop version.
- **Force HLS update** button – manually regenerates the stream segments if the player freezes.
- Keyboard shortcuts: `Space` (play/pause), `←/→` (seek ±2s), `Enter` (jump to selected rally), `F` (favorite).

## Search Examples

Use the underscore `_` as a wildcard for exactly one character. Examples:

- `a__S_#` → finds serves (`S` as 4th character) with a `#` evaluation.
- `*__SQ#` → finds quick sets (`SQ`) with a `#`.
- `a05_` → finds codes starting with `a05` and any 4th character.

## Troubleshooting

- **No video in web player** – Check that `ffmpeg.exe` is present and the snapshot file exists in the `data/stream` folder. Try clicking "Force HLS update".
- **VLC not found** – Install VLC Player (64‑bit) and restart the application.
- **List of rallies not updating** – Verify that the `.dvw` file is being written by DV4. Use the "Reload" button in the web interface.
- **Port 5000 already in use** – Change the port in application, contacting Ori.
